# AI Desk 15–20 Draft Pilot\n\nThe newsroom pilot is intentionally designed to test quality before adding paid AI spend.\n\n## Target\n\n- 15–20 unique AI drafts per Bangladesh calendar day.\n- The same event reported by multiple outlets becomes one story cluster and one draft.\n- The pipeline ranks candidates by source coverage, freshness and editorial importance.\n- A hard daily AI-draft cap of 20 prevents the free-tier pilot from running away with quota.\n- The scheduler runs every 30 minutes with one AI worker.\n\n## Required production setup\n\n1. Run `supabase/sql/001_ai_desk_source_expansion.sql` once in the live News Supabase SQL Editor.\n2. In Vercel Production, set `GEMINI_API_KEY`.\n3. In Vercel Production, set `CRON_SECRET` or `DESK_CRON_SECRET`.\n4. In Vercel Production, verify the existing Supabase URL/publishable key/service secret variables are present.\n5. In GitHub repository secrets, keep `DESK_CRON_SECRET` matching the Vercel cron secret.\n6. Do not add Gemini billing during the pilot.\n\n## What to watch\n\nAfter 24–72 hours, compare:\n\n- raw RSS items fetched\n- unique story clusters\n- AI drafts created\n- duplicate drafts\n- Gemini 429/5xx failures\n- stories stuck in `researching`\n- average editor corrections before publish\n\nIf the system has plenty of high-quality candidates but repeatedly hits Gemini limits, then paid API capacity becomes the next bottleneck to evaluate. Until then, keep the free-tier pilot.
